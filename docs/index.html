MiniOps.jl

Matrix-free linear operators for inverse problems in Julia.

MiniOps is based on a simple idea: operators are defined by forward and adjoint actions, not matrices.

Features

  • Forward / adjoint operators
  • Operator composition
  • Adjoint testing
  • FFT-based operators
  • Radon transforms (explicit and chirp-based)

Quick Example


using MiniOps

A = fft_op()
y = A * x
xadj = A' * y
