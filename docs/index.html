MiniOps.jl

Matrix-free operators for inverse problems in Julia

Operators, not matrices

MiniOps implements linear operators using forward and adjoint actions. No matrices. Just clean, composable operators. 


y = A * x
x = A' * y

Why MiniOps?

  • Matrix-free inverse problems
  • Exact adjoint operators
  • Composable operator algebra
  • FFT-based implementations
  • Radon transforms (explicit + chirp)

Example


using MiniOps

R = radon_tx_tp_chirp_op(dt, x0, dx, nx, p0, dp, np)

d  = R * m      # τ-p → t-x
ma = R' * d     # adjoint
